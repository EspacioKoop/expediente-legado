# Referencias ludonarrativas transversales

> Investigación de diseño asociada a #1432. Este documento **informa** decisiones; no declara mecánicas integradas ni autoriza trabajo fuera del issue dueño.

## Propósito

*Expediente Legado* funciona mejor cuando la investigación no consiste en revelar una solución oculta, sino en construir una lectura provisional a partir de material incompleto. Este corpus reúne referencias externas útiles para cuatro verbos del proyecto:

**leer → relacionar → interpretar → convivir con la incertidumbre**

La influencia debe traducirse siempre a una técnica abstracta. No se copian personajes, escenas, diálogos, música, interfaz reconocible, iconografía, assets ni estructuras protegidas.

## Invariantes del proyecto

Toda propuesta derivada de estas referencias debe respetar:

- un documento, reconstrucción o sueño no inventa hechos fuera del catálogo;
- el jugador puede distinguir **hecho catalogado**, **testimonio**, **versión institucional**, **inferencia propia** y **deformación onírica**;
- una ambigüedad diseñada debe proceder de fuentes o reglas legibles, no de inconsistencias accidentales;
- SIGA-98 sigue siendo herramienta, espacio narrativo y sistema burocrático, no una colección de minijuegos desconectados;
- ideologías, religión, mitologías, literatura y Tarot pueden cruzarse, pero mantienen contratos y fuentes de verdad separadas;
- una referencia nunca sustituye un playtest ni justifica una feature por reconocimiento cultural.

## Gramática de evidencia y reconstrucción 3D

Una reconstrucción debe representar una **lectura provisional**. El modelo conceptual recomendado es:

```text
hechos catalogados conocidos
+ fuente/punto de vista seleccionado
+ relaciones registradas por el jugador
+ huecos explícitos
= reconstrucción provisional
```

Nunca:

```text
reconstrucción 3D
= verdad canónica secreta
```

### Estados de información

Conviene etiquetar internamente cada elemento usado por una reconstrucción con uno de estos roles:

- **HECHO**: dato que el catálogo presenta como verificable dentro del caso.
- **TESTIMONIO**: afirmación atribuida a una fuente.
- **INSTITUCIONAL**: versión asentada en informe, acta, SIGA o procedimiento.
- **INFERENCIA**: relación que el jugador ha registrado; no crea un hecho nuevo.
- **HUECO**: información necesaria para completar una representación que no está disponible.
- **DEFORMACIÓN**: transformación de presentación permitida en sueño; nunca una pista nueva.

Una misma escena puede cambiar al activar otra fuente. Debe cambiar **la representación**, no reescribir el documento original.

### Convenciones visuales sugeridas

Sin fijar una estética única:

- conservar elementos confirmados entre versiones;
- hacer visibles los huecos mediante ausencia, silueta, posición incierta o discontinuidad;
- vincular cada diferencia importante a una fuente consultable;
- permitir alternar dos versiones cuando exista contradicción;
- no usar “más detalle gráfico” como sinónimo de “más verdad”;
- al saltar la escena, conservar exactamente el mismo estado jugable.

Esto complementa las reconstrucciones documentales de #286 y las reglas de presentación de #177.

## SIGA-98 / OS98 como espacio narrativo

La referencia combinada de *Roottrees*, *Her Story*, *Hypnospace Outlaw*, Kafka, Lem y *Brazil* sugiere una dirección coherente para #533:

1. **Buscar es actuar.** Las palabras, fechas, nombres, identificadores y metadatos que el jugador aprende deben abrir caminos de consulta.
2. **La interfaz tiene autor.** Formularios, mensajes, nombres de programas y restricciones reflejan la institución que los construyó.
3. **El error también cuenta historia.** Una referencia rota, un documento duplicado o una orden contradictoria puede tener función narrativa si está catalogada, es reproducible y no parece un bug.
4. **El escritorio recuerda.** Historial, archivos recientes, notas y organización pueden expresar el trabajo realizado sin añadir una barra abstracta.
5. **1998 limita posibilidades.** Evitar comportamientos de buscador/red modernos si erosionan la ficción tecnológica; la incomodidad debe ser deliberada pero usable.

## Sueño, memoria y realidad subjetiva

A partir de *SIGNALIS*, *1000xRESIST*, *Perfect Blue*, *Twin Peaks*, *Lost Highway* y *Ubik*:

- el sueño reutiliza material conocido;
- una variación debe depender de estado persistido o de una regla simbólica estable;
- puede cambiar escala, iluminación, continuidad, sonido, espacialidad o presencia de objetos;
- no puede presentar como recuerdo algo que el jugador nunca conoció;
- un objeto recurrente funciona mejor si acumula significados procedentes de vida cotidiana real;
- la incertidumbre debe sobrevivir al sueño: el sueño no es un oráculo de la solución correcta.

Refs #435, #787 y #1182.

## Burocracia e ideologías

La combinación de *Brazil*, Kafka, Lem, *Pentiment*, *Disco Elysium* y *Foucault's Pendulum* permite separar dos capas:

### Institución

La burocracia puede producir consecuencias mediante:

- qué información acepta como válida;
- qué campos obliga a completar;
- qué discrepancias ignora o escala;
- quién puede firmar, revisar o recurrir;
- qué queda en el registro frente a lo vivido.

### Interpretación

Las ideologías pueden afectar:

- vocabulario disponible;
- qué contradicciones llaman antes la atención;
- asociaciones simbólicas;
- lecturas de medios, literatura y cultura;
- consecuencias y epílogos derivados de elecciones observables.

No deben actuar como multiplicadores ocultos de “verdad”, inteligencia o moralidad. Una doctrina puede cambiar la **lectura** de un expediente; no los hechos catalogados del expediente.

Refs #915–#925.

## Criterio para futuras propuestas

Antes de citar una obra como justificación de diseño, responder:

1. ¿Qué técnica abstracta estamos estudiando?
2. ¿Qué problema observable del juego resuelve?
3. ¿Qué estado existente consume?
4. ¿Qué información puede mostrar sin inventar hechos?
5. ¿Qué riesgo introduce?
6. ¿Qué issue posee la implementación y qué gate debe pasar?
7. ¿Funcionaría para una persona que no conoce la referencia?

Si alguna respuesta falta, la referencia todavía es investigación, no especificación.
