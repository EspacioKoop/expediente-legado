# World Mythology Reference for Expediente Legado

This directory contains compiled mythology data from various sources:
- mythologies.wiki (31 traditions)
- ACP framework (templeoflum/ACP) - 580 archetypes with 8-dimensional coordinates
- Mythos Atlas (pantheons of ancient civilizations)
- Comparative mythology research

## Contents

- `overview.md` - High-level patterns and cross-cultural themes
- `traditions/` - Individual tradition files with deities, creatures, cosmology
- `archetypes/` - ACP-derived archetype definitions (JSON)
- `relationships.md` - Relationship types from ACP (for faction dynamics)
- `spectral-axes.md` - Explanation of the 8 spectral axes for stat mapping

## Usage

This data can inform:
- Character archetypes and backstories
- Faction and pantheon design
- Quest motifs (hero journey, flood, underworld descent)
- Dialogue and mythic references
- Procedural generation of myths

See also: [docs/research/](..) for other worldbuilding references.
