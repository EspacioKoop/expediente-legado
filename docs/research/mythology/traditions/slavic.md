# Slavic Mythology

Source: mythologies.wiki, ACP (16 Slavic pantheon), comparative sources

## Key Themes
- Nature spirits (domovoi, leshy, rusalka, vodyanoy)
- Dual faith (dvoeverie) - Christianity + folk tradition
- Seasonal calendar rituals
- Ancestor veneration
- Household/field/forest spirit hierarchy
- Thunder god vs serpent/dragon

## Pantheon Structure
**Major Deities:**
- Perun (thunder, oak, warrior, supreme)
- Veles (cattle, wealth, underworld, magic, trickster)
- Svarog (sky, fire, forge)
- Dazhbog (sun, prosperity)
- Mokosh (earth, fertility, women's work)
- Lada (love, beauty, harmony)
- Yarilo (spring, fertility)
- Zorya (dawn/dusk guardians)
- Stribog (winds)
- Simargl (fire, protection)

**Spirits:**
- Domovoi (household)
- Leshy (forest)
- Vodyanoy (water)
- Rusalka (water maidens)
- Polevik (field)
- Bannik (bathhouse)

## Notable Creatures
- Zmey Gorynych (3-headed dragon)
- Firebird (Zhar-ptitsa)
- Alkonost, Sirin (bird-maidens)
- Koschei the Deathless (lich-like)
- Baba Yaga (witch, ambiguous)
- Gamayun (prophetic bird)

## Shared Motifs
- Flood: Not central
- Dying God: Yarilo (dies/returns annually)
- World Tree: Oak as world tree (sometimes)
- Trickster: Veles (cattle thief, shape-shifter)
- Underworld Journey: Nav (underworld), Veles as guide

## Game Design Notes
- Dual faith = syncretism mechanics
- Spirit negotiation (offerings, respect, taboos)
- Seasonal rituals as game calendar
- Household/field/forest as territory types
- Perun-Veles as cosmic duality (order/chaos)
