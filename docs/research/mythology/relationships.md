# ACP Relationship Types

From the Archetypal Context Protocol, these 17 typed connections define how archetypes relate across systems and within pantheons. Useful for faction dynamics, alliance systems, and narrative arcs.

## Relationship Types

1. **POLAR_OPPOSITE** - Opposite end of a spectral axis
   - Examples: Zeus-Hades (Ascent/Descent), Athena-Ares (Order/Chaos)
   - Game use: Factional opposition, moral dilemmas, shadow aspects

2. **SHADOW** - Repressed/distorted form
   - Examples: Zeus as Tyrant, Ares as Sadist
   - Game use: Corruption paths, fallen hero arcs, dark mirrors

3. **COMPLEMENT** - Balances and completes
   - Examples: Zeus-Hera (king/queen), Odin-Frigg (action/acceptance)
   - Game use: Ally systems, romantic pairings, balanced teams

4. **EVOLUTION** - Transforms into (forward)
   - Examples: Maiden → Mother → Crone, Innocent → Orphan → Wanderer
   - Game use: Progression systems, character arcs, initiation paths

5. **DEVOLUTION** - Transforms into (backward)
   - Examples: Crone → Mother → Maiden
   - Game use: Regression, fall from grace, memory mechanics

6. **CULTURAL_ECHO** - Same pattern, different system (with fidelity 0.0-1.0)
   - Examples: Zeus-Jupiter (0.95), Odin-Hermes (0.5 wisdom)
   - Game use: Syncretism, cultural adaptation, pantheon mapping

7. **INSTANTIATES** - Embodies meta-archetype
   - Examples: Hermes instantiates Trickster (0.85), Psychopomp (0.65)
   - Game use: Class/multiclass systems, archetype weights

8. **TENSION** - Productive dialectical pull
   - Examples: Order-Chaos tension creates dynamism
   - Game use: Conflict resolution, balance mechanics

9. **MIRRORS** - Same pattern, different domain
   - Examples: Athena-Minerva (wisdom/war across pantheons)
   - Game use: Parallel characters, recurring motifs

10. **CONTAINS** - Embodies aspect of primordial
    - Examples: Zeus contains Warrior (defender of order)
    - Game use: Aspect systems, domain specialization

11. **ALLY** - Friendly cooperation
    - Examples: Athena-Odysseus (patron-protected)
    - Game use: Quest givers, faction allies, support roles

12. **ANTAGONIST** - Active opposition
    - Examples: Zeus-Prometheus (authority vs rebellion)
    - Game use: Villains, obstacles, rival factions

13. **PRECEDES** - Comes before in sequence
    - Examples: Cronus precedes Zeus (Titan age before Olympian)
    - Game use: Historical ages, technological progression

14. **CONSTELLATION** - Group of related archetypes
    - Examples: Ragnarök Monsters (Fenrir, Jörmungandr, Hel)
    - Game use: Enemy waves, boss rushes, thematic encounters

15. **TRANSCENDS** - Goes beyond typical expression
    - Examples: Hestia transcends Great Mother (pure center)
    - Game use: Ultimate forms, enlightened states

16. **SYNTHESIS** - Combination creates new archetype
    - Examples: Hermes + Thoth = Hermes Trismegistus
    - Game use: Fusion mechanics, hybrid classes

17. **DEVELOPMENTAL_ARC** - Life stages (origin, ascent, mastery, integration)
    - Not a relationship type per se but included in ACP data
    - Game use: Character backstories, progression templates

## Usage in Expediente Legado

- **Faction Systems**: Allies (COMPLEMENT/ALLY), Antagonists (ANTAGONIST/POLAR_OPPOSITE)
- **Character Progression**: EVOLUTION paths, DEVOLUTION for corruption
- **Pantheon Design**: CULTURAL_ECHO for syncretic deities, INSTANTIATES for class weights
- **Narrative Design**: TENSION for conflict, MIRRORS for recurring themes
- **Mechanical Mapping**: Axes often define POLAR_OPPOSITE pairs (e.g., Zeus-Hades on Ascent/Descent)

## Example: Zeus Relationships
- POLAR_OPPOSITE: Hades (Ascent/Descent axis)
- COMPLEMENT: Hera (king/queen dynamic)
- ANTAGONIST: Prometheus (authority vs rebellion)
- SHADOW: Tyrant archetype (when authority becomes oppression)
- CULTURAL_ECHO: Jupiter (Roman, 0.95 fidelity), Indra (Hindu, 0.6 thunder aspect)
- CONTAINS: Warrior aspect (defender of cosmic order)
