# Spectral Axes

The ACP framework defines eight spectral axes, each a spectrum from 0.0 (negative pole) to 1.0 (positive pole). These can be used to map archetypes to personality traits, moral alignments, or magical affinities.

## Axes Detail

1. **Order ↔ Chaos**
   - Order: Structure, law, pattern, stability
   - Chaos: Entropy, freedom, disruption, dissolution
   - Examples: Lawgiver (Order 0.0) → Trickster (Chaos 0.75) → Primordial Chaos (Chaos 1.0)

2. **Creation ↔ Destruction**
   - Creation: Genesis, building, growth
   - Destruction: Ending, breaking, transformation (necessary for renewal)
   - Examples: Pure generative force (Creation 0.0) → Preserver (Balanced 0.5) → Transformative ending (Destruction 0.75) → Pure dissolution (Destruction 1.0)

3. **Light ↔ Shadow**
   - Light: Conscious, revealed, known, clarity
   - Shadow: Unconscious, hidden, repressed, mystery
   - Examples: Pure solar consciousness (Light 0.0) → Liminal threshold (Balanced 0.5) → Underworld wisdom (Shadow 0.75) → Pure unconscious depths (Shadow 1.0)

4. **Active ↔ Receptive**
   - Active: Yang, projective, initiating, doing
   - Receptive: Yin, absorptive, responding, being
   - Examples: Pure initiating force (Active 0.0) → Strategic action (Active 0.25) → Balanced responsive (0.5) → Nurturing receptivity (Receptive 0.75) → Pure receptive stillness (Receptive 1.0)

5. **Individual ↔ Collective**
   - Individual: Self, ego, personal, hero
   - Collective: Group, transpersonal, tribe, world soul
   - Examples: Pure ego-consciousness (Individual 0.0) → Individual within community (0.25) → Mediator (Balanced 0.5) → Voice of collective (Collective 0.75) → Pure collective unconscious (Collective 1.0)

6. **Ascent ↔ Descent**
   - Ascent: Sky, spirit, transcendence, above
   - Descent: Earth, matter, immanence, below
   - Examples: Pure sky/spirit (Ascent 0.0) → Solar height (Ascent 0.25) → Threshold between worlds (Balanced 0.5) → Earth-rooted (Descent 0.75) → Pure underworld/depth (Descent 1.0)

7. **Stasis ↔ Transformation**
   - Stasis: Preservation, continuity, stability, permanence
   - Transformation: Change, metamorphosis, flux, impermanence
   - Examples: Eternal unchanging (Stasis 0.0) → Stable growth (Stasis 0.25) → Cyclical renewal (Balanced 0.5) → Active transformation (Transformation 0.75) → Pure metamorphosis (Transformation 1.0)

8. **Voluntary ↔ Fated**
   - Voluntary: Free choice, agency, self-determination, will
   - Fated: Destiny, necessity, cosmic inevitability, prophecy, karma
   - Examples: Pure agency (Voluntary 0.0) → Strategic choice within constraints (Voluntary 0.25) → Choice and fate intertwined (Balanced 0.5) → Instrument of destiny (Fated 0.75) → Pure fate/necessity (Fated 1.0)

## Usage in Expediente Legado

- **Character stats**: Map axes to trait sliders (e.g., Law/Chaos, Light/Dark, Fate/Free Will)
- **Archetype definition**: Each primordial and specific archetype has coordinates
- **Relationship dynamics**: Polar opposites often lie on same axis (e.g., Zeus-Hades on Ascent/Descent)
- **Transformation arcs**: Movement along axes during story (e.g., increasing Transformation, decreasing Stasis)
