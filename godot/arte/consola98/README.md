# Consola 98 — arte de #95

Arte original para **Caza Píxeles 98**, **Paper Planes 98** y **Croc Riders 98**.

## Integración

- `cartuchos/`: etiquetas ligeras usadas en runtime por `ConsolaSobremesa98` para los tres cartuchos decorativos del rincón de televisión.
- El arte se carga solo como `Texture2D`; los props no cargan ROMs ni alteran campaña.

`Paper Planes 98` conserva como motivo visual la Nueva York de 1998 y `Croc Riders 98` usa una composición pulp de acción mucho más marcada.

No se incluyen BIOS, ROMs de terceros ni logos de hardware comercial.
