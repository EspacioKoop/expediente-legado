# Procedencia — identidad visual Bit 98

Assets originales para #676, derivados de la dirección visual aprobada por @eGurucharri el 2026-09-21.

- El moodboard de referencia fue generado con el modelo de imágenes de OpenAI para EspacioKoop.
- Los SVG de este directorio son redibujos originales y simplificados para uso directo en Godot.
- No contienen marcas, logotipos, personajes ni carátulas de terceros.
- Las portadas de videojuegos que se muestran junto a esta identidad se reutilizan desde assets ya existentes del propio repositorio; este paquete no redefine sus títulos ni su arte.
- Uso: rótulo exterior/interior, cartelería POP y señalética diegética de Bit 98.
