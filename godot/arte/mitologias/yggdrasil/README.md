# Yggdrasil y Nornas — raíces y causalidad (#653)

Pack de arte de primera parte para reforzar el vertical existente sin caer en estética de «vikingo de acción».

## Contenido

- `raiz_puente.obj`: raíz-pasarela de cinco tramos low-poly.
- `nudo_raices.obj`: nudo central reutilizable como nodo causal.
- `hebras_causales.svg`: red de conexiones visibles entre nodos.
- `corteza_terminal.svg`: motivo original de corteza + terminal incrustado.
- `yggdrasil.mtl`: materiales compartidos.

## Uso

Los OBJ trabajan en unidades aproximadas a metros. Están pensados como sustitutos visuales de pasarelas, raíces y nodos procedurales ya existentes, sin imponer colisión ni comportamiento.

Los SVG no contienen runas ni alfabetos pseudo-nórdicos: solo líneas, fibras, nodos y geometría técnica para hacer legible la causalidad a distancia.

## Límites

El diseño sigue `docs/assets/yggdrasil-referencias.md` y evita presentar reconstrucciones modernas como hechos medievales. Las «hebras» son una traducción visual original del contrato de conexiones del juego, no una representación arqueológica.

Arte original para este repositorio. Sin PNG/GLB para no saltarse Git LFS.
