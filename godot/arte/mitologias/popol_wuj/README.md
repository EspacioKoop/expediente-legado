# Popol Wuj / Xibalbá — pares, eco y correspondencia (#655)

Pack de arte de primera parte para reforzar el vertical k’iche’ ya existente sin fabricar iconografía histórica.

## Contenido

- `portal_pareado.obj`: dos marcos espaciales relacionados pero no idénticos.
- `piedras_eco.obj`: pareja de piedras/volúmenes con muescas complementarias para feedback causal.
- `panel_correspondencias.svg`: composición gráfica de pares y simetrías.
- `reflejo_causal.svg`: rutas gemelas conectadas por ecos visuales.
- `popol_wuj.mtl`: materiales compartidos.

## Uso

Los OBJ emplean unidades aproximadas a metros y están pensados como sustitutos visuales de los pares procedurales del sueño. No codifican reglas: el runtime conserva la causalidad y equivalencia ya implementadas.

Los SVG son gráficos contemporáneos originales. No contienen glifos mayas inventados, escritura pseudoepigráfica ni motivos arqueológicos copiados.

## Límites culturales

La documentación del vertical en `docs/assets/popol-wuj-referencias.md` distingue el Popol Wuj k’iche’ de una estética «maya» genérica. Este pack se limita por tanto a la gramática mecánica del issue —parejas, eco, correspondencias y reflejos causales— y no pretende reconstruir Xibalbá ni una arquitectura histórica.

Arte original para este repositorio. Sin PNG/GLB para no saltarse Git LFS.
